This repository contain Verilog code for multiple types of latches and flip flops along with a clock divider.

1.Create project in Vivaldo using correct FPGA selected
2.Move display driver code into source file
3.Assign inputs and outputs on FPGA usings provided file
4.Add constraint to add test bench 
5.Run Simulation to check wave form (Test benches should show values in comments)
6.Run synthesis and check resulting gate level results
7.Create bit stream
8.Program FPGA
9.Test FPGA by checking for difference in brightness between LED's due to different clock cycles
